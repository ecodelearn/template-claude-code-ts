# Security policy / Política de segurança

## English

Do not disclose vulnerabilities, credentials, private repository data, or working
exploits in public issues.

Report security concerns through GitHub's private vulnerability reporting feature
when enabled. If it is unavailable, contact the repository owner privately through
the contact channel listed on the `ecodelearn` GitHub profile.

Include the affected commit/version, provider, operating system, reproduction
steps, expected impact, and a minimal proof of concept without real secrets.

Maintainers will acknowledge the report, assess severity, prepare a fix and
coordinate disclosure. No guaranteed response SLA is currently offered.

Supported code is the current `master` branch. The npm package is not yet
published.

## Português do Brasil

Não divulgue vulnerabilidades, credenciais, dados de repositórios privados ou
exploits funcionais em issues públicas.

Use o recurso privado de reporte de vulnerabilidade do GitHub quando habilitado.
Se indisponível, contate o responsável de forma privada pelo canal indicado no
perfil GitHub `ecodelearn`.

Inclua commit/versão afetada, provider, sistema operacional, passos de reprodução,
impacto esperado e uma prova mínima sem segredos reais.

Os mantenedores confirmarão o recebimento, avaliarão severidade, prepararão a
correção e coordenarão divulgação. Ainda não existe SLA garantido.

O código suportado é a branch `master`. O pacote npm ainda não foi publicado.
